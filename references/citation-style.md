# 参考文献及引用规范

在清理正文引用、生成参考文献列表、迁移 Markdown 到 LaTeX、或核对文献卡片时加载本文件。

## 基本规则

- 正文采用顺序编码制。参考文献编号按正文首次引用顺序排列。
- 正文引用采用数字序号上标形式，例如 `研究表明……<sup>[1]</sup>` 或 LaTeX 模板支持的等价上标引用命令。
- Markdown 草稿可用 `[1]`、`<sup>[1]</sup>` 或项目约定的临时标记；转换到 LaTeX 时保留并统一为模板要求的 `\cite{}` 或上标引用形式。
- 一个事实性论断如果依赖文献、标准、协议、报告或产品资料，必须能追溯到对应引用。
- 引用论文时，正文通常不重复年份；写作口径优先为“Novo 提出……”“程冠杰等综述……”。标准发布、协议版本、技术阶段划分、工程事件可保留必要年份。
- 不要用参考文献替代本文实验结论。文献只能证明已有研究、技术背景或设计依据，不能证明本文系统已经达到某性能或安全效果。

## 文献列表

- 文献列表按正文首次引用顺序编号，不按作者字母序。
- 中文文献保留中文标点和中文题名；英文文献保留英文题名、期刊名、会议名、出版机构和页码等原始信息。
- 列表条目应至少包含主要责任者、题名、文献类型、出版源和年份；期刊论文还应包含期刊名、卷期和页码，会议论文还应包含会议或论文集信息。
- 学位论文、技术报告和标准按 GB/T 7714-2015 著录，并保留文献类型标识 `[D]`、`[R]`、`[S]`。
- 标准、Recommendation、RFC、Internet-Draft、白皮书或机构规范如果没有传统出版地，可使用机构名、编号、版本或发布日期保持可检索性。

## 常见类型格式

### 期刊论文

```text
[序号] 主要责任者. 题名[J]. 期刊名, 年份, 卷(期): 起止页码.
```

示例：

```text
[1] Gang Dong. Intelligent greenhouse control system design based on rf technology research[J]. Applied Mechanics and Materials, 2014, 687-691: 64-67.
```

### 学位论文

```text
[序号] 主要责任者. 学位论文名[D]. 保存地点: 保存单位, 年份.
```

示例：

```text
[1] 马欢. 人类活动影响下海河流域典型区水循环变化分析[D]. 北京: 北京大学, 2011.
```

### 技术报告

```text
[序号] 主要责任者. 报告题名[R]. 出版地: 出版者, 年份.
```

示例：

```text
[1] Scott Rose, Oliver Borchert, Stu Mitchell, Sean Connelly. Zero Trust Architecture[R]. Gaithersburg: National Institute of Standards and Technology, 2020.
```

### 标准和协议

```text
[序号] 主要责任者. 标准编号: 标准题名[S]. 出版地: 出版者, 年份.
```

没有独立标准编号但属于标准、Recommendation、RFC 或 Internet-Draft 的资料，可将编号或资料类型写入题名，仍按 `[S]` 处理。

示例：

```text
[1] 标准化组织. 标准编号: 标准题名[S]. 出版地: 出版者, 年份.
```

### 图书

```text
[序号] 主要责任者. 书名[M]. 出版地: 出版者, 年份.
```

示例：

```text
[1] Maurice Herlihy, Nir Shavit. The Art of Multiprocessor Programming[M]. Beijing: China Machine Press, 2009.
```

## 引用质量检查

- 每个引用都应在正文中承担明确功能：背景事实、研究进展、方法依据、标准依据、对比对象或问题归纳。
- 不为凑数量堆砌文献；同一段落连续引用多篇文献时，应说明它们共同支持的结论或差异。
- 国内外研究现状中不按国家做成熟度评价，不写“国内资料少于国外”等元评论。
- 文献卡片中的摘要、贡献、不足和可用论据应与最终引用口径一致；不能把卡片中的初步判断直接当成论文结论。
- 参考文献条目缺作者、年份、题名或来源时，先补充元数据；无法补充时不要作为正式参考文献。
